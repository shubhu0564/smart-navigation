# Gulmohar JVPD Smart Navigation
A GIS-based route and landmark navigation system for the Gulmohar JVPD area, built with React, Vite, Leaflet, and GeoJSON.

## Features
- Map-based search for landmarks, roads, and public amenities
- Marathi and English language support
- Simplified landmark popups with Google Maps directions
- Public representative cards and local civic support

## Local development
1. Install dependencies:
   - `npm install`
2. Start the development server:
   - `npm run dev`
3. Build for production:
   - `npm run build`
